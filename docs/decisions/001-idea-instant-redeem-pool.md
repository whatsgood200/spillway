# 001: Build a self-settling withdrawal queue with an instant-redeem pool

Date: 2026-11-15. Decided by Right.

## Decision
Enter Every Second Counts with a vault withdrawal queue that a reactive contract settles the moment liquidity returns, plus a pool that buys queue places for cash now.

## Why
- The organisers list "withdrawal queues that settle the moment they can" and "liquidity that moves to wherever it's needed" as ideas. On 2026-11-15 none of the 23 entries did either; stop-loss (4) and arbitrage (3) filled the track.
- No past Reactive winner or official demo covers withdrawal-queue settlement.
- The design is proven elsewhere: Sanctum's instant unstake reserve on Solana. Two 2026 ETHGlobal projects (intentional.so, RWA Outlet) built "a pool buys the claim" and left claim and repay to a manual step or a bot.
- Speed matters for a concrete reason: freed liquidity is contested, so one second against seven changes who gets paid.
- All eight inspected entries in the track run on their own mock pools. Morpho Blue is live and permissionless on Base Sepolia, so we can run on real protocol code.

## Rejected
- A Rahasya style private AI chat: no event to callback loop, so it fails the Execution gate; the AI track also pays half.
- Cross-chain lead-pool fee hook: sound, but it only narrows a stale-price window and Reactive has already judged six hook projects.
- Meteora style utilization rebalancer and Hyperliquid style backstop liquidation: viable, kept as reserve ideas.

## Tradeoffs accepted
- Testnet activity is generated by us and must be labelled as ours.
- The cross-chain refill needs a CCTP attestation relayer, so it is a slower secondary leg and not the measured loop.

## Correction, same day
The claim that no entry does withdrawal-queue settlement was true of the DoraHacks list only. A GitHub search found two entrants building a self-settling queue (`sainath998/instant-queue`, `emilhuseyn/reactive-omni`), both on mock vaults with small samples. The queue alone is no longer original here. What remains unbuilt in this field: the pool that buys queue places, settlement driven by a real lending protocol's events, the race experiment, and millisecond timing. Whether to keep the idea with the pool as the headline or switch is Right's call.
